# Project Description

This is a simple Python calculator project.

## Purpose

The project was created to practise Git and GitHub workflows, including commits, branches, merging, and pushing code to a public repository.

## Features

- Displays the student's name and the current date
- Adds two numbers
- Subtracts two numbers
- Multiplies two numbers

## Project Structure

- `src/main.py` runs the program
- `src/utils.py` contains calculator functions
- `README.md` introduces the project
